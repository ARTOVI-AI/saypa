# Saypa

**Быстрее, чем печатать.** Десктоп-утилита для Windows: зажал горячую клавишу → говоришь → распознанный текст вставляется в активное поле. Работает в любом приложении.

## Возможности
- Распознавание речи в облаке NVIDIA Riva (Whisper, gRPC)
- Горячая клавиша: удержание или переключение
- История записей: прослушивание (WAV), копирование, **экспорт всех в один файл** (TXT / HTML / MD / XML)
- Настраиваемый порядок кнопок, тёмная/светлая тема, языки интерфейса: Русский / English / Українська
- Сворачивание в трей, автозапуск с Windows
- **Автообновление** через GitHub Releases

## Установка
1. Скачайте `Saypa.exe` из раздела [Releases](https://github.com/ARTOVI-AI/saypa/releases/latest) и запустите.
2. Требуется [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0).
3. При первом запуске укажите бесплатный API-ключ NVIDIA (кнопка «?» в настройках подскажет, где взять).
